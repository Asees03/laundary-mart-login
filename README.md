# Split Layout Login Page

A simple and responsive login page built using HTML and CSS Flexbox.

### Features

* Split-screen layout
* Email and password input fields
* Login button
* Centered login form
* Responsive design

### Technologies Used

* HTML5
* CSS3
* Flexbox

### Project Structure

* index.html – Page structure
* styles.css – Styling and layout


### How to Run

Open index.html in your web browser.

**Note:** This project demonstrates a front-end login interface and does not include backend authentication.
